# 后续维护

本文件替代上一版基于动态 sprite 猫咪的升级清单。当前版本以原版互动橘猫与宋式三维雅间为中心，当前范围见 [项目现状](project-overview.md)。

## 维护原则

- 内容精简，不恢复用户删除的 AI 分工工作台、未完成陈列室，不增加文章更新负担。
- 企业项目只使用可公开介绍，个人贡献与团队成果保持区分。
- 雅间使用本地 Three.js 绘制，四季与天气是用户选择的设定，不是真实气象数据或在线模型推理。
- 新功能优先强化一个主玩法，避免堆叠独立小游戏。
- 雅间配置显式保存到本机；升级不要自动删除旧版收藏数据。
- 修改场景后检查全部季节/天气组合、最长题名、屋顶开合、镜头、导出与 WebGL 降级。
- 新增 ES module 或资源时运行构建产物检查；部署需要正确的 `.mjs` MIME。

## 可选演进

不属于本次交付的承诺：更多雅间陈设、镜头预设、用户主动授权的跨设备设置同步。如果以后接入真实 AI，需要单独设计服务端凭证管理、成本限制与失败降级，不能将密钥放入浏览器。
