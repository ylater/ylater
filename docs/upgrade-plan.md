# 后续维护

本文件替代上一版基于动态 sprite 猫咪的升级清单。dev 重设计已以原生生成主视觉和灵感画布为中心，当前范围见 [项目现状](project-overview.md)。

## 维护原则

- 内容精简，不恢复用户删除的 AI 分工工作台、未完成陈列室，不增加文章更新负担。
- 企业项目只使用可公开介绍，个人贡献与团队成果保持区分。
- 画布使用本地算法，明确能力边界，不把它包装成真实模型推理。
- 新功能优先强化一个主玩法，避免堆叠独立小游戏。
- 数据持久化要解释保存位置、容量与删除方式；不得静默覆盖收藏。
- 修改构图后检查所有配色、强度端点、最长中文和 emoji 输入及导出文件。
- 新增 ES module 或资源时运行构建产物检查；部署需要正确的 `.mjs` MIME。

## 可选演进

不属于本次交付的承诺：更多程序构图、海报配方 JSON 导入导出、用户主动授权的跨设备收藏。如果以后接入真实 AI，需要单独设计服务端凭证管理、成本限制与失败降级，不能将密钥放入浏览器。
