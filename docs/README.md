# 项目文档导航

| 文档 | 用途 |
| --- | --- |
| [项目现状](project-overview.md) | 产品边界、功能、架构、模块协作和素材约束 |

开发命令与素材处理步骤见根目录 [README](../README.md)。开始改造前先阅读现状，再按需求选择升级项，完成后更新现状和验收记录。

文档中的“已实现”表示源码存在对应实现，不代表已经通过浏览器验收。“建议”不代表已经确定的产品需求。
