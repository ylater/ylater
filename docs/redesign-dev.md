# 上一版 dev 个人站重设计：海报画布

本文件保留上一版设计过程。当前 studio 已改为宋式雅间，见 [本版升级](song-room-upgrade.md)。

## 目标与方向
2026-10-09。极简、趣味、个性张扬；个人主页，不是企业产品宣传页。不恢复此前删除的 AI 分工工作台或未完成陈列室，不引入文章更新负担。

视觉：白色画布、炭黑标题、荧光绿与橘色点缀。大字和真实生成的角色资产承担视觉，避免卡片堆叠。中文为主，英文只承担姓名与少量作品属性。

## 交付范围
- 首页重新设计：个人定位、可交互主视觉、工作方向与说明书。
- 灵感画布：输入短句，本地确定性程序生成艺术海报，支持参数、重新混合、下载 PNG、分享 URL。
- 本机收藏：IndexedDB 保存海报配方，支持恢复、删除，存储失败有明确反馈。无访客跟踪，不伪装多人作品墙。
- 一站式理赔：保留入院感知、住院协同、出院理赔情境玩法。
- 原生 imagegen 生成项目角色资产，保存原始提示词与使用位置，不调用图片 API。
- 响应式、键盘、减少动效；代码检查、单元测试、构建与实际浏览器 UI 验收。

## 架构决定
沿用零运行时依赖的 HTML/CSS/JS。轻量数据库使用浏览器 IndexedDB；分享配方编码在 URL 中，不需要部署额外数据库、账号或凭证。在线 AI 调用不在本版假装实现，画布明确标识本地生成算法。
