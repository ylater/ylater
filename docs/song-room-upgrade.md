# 宋式雅间与原版橘猫升级

2026-10-10，dev 分支。

## 用户目标

1. hero-object 恢复上一版 pet 橘猫与原有互动。
2. studio 替换为宋式雅间，可个性化定义，支持四季与天气切换。
3. headline 保留当前黑色大字与荧光绿手绘下划线，恢复点击换词并加入定时切换。

## 源码依据

用户提供 `/Users/murphy/Downloads/index.html`，完整、原样保留在 `artwork/song-room/original.html`。两者 SHA-256 相同：`4396a3c739396947f72cb641a1115790a9dbea47216295aec24cb6d1cf90cc01`。

与[原站松风茶肆](https://song-corner-songfeng.murphydeng.chatgpt.site/)对照：三维模块相同，线上页面额外含托管注入脚本，集成版未复制该注入内容。原站只作为参考，不修改其部署。

`src/song-scene.mjs` 沿用原始几何体、程序纹理、材质、批处理和 OrbitControls，在容器内挂载，新增生命周期、四季、天气、灯光、题名和快照。没有用图片替代三维场景。

## 实现

- 橘猫使用原 `public/pet/heyanju.webp` 动画图集与 `heyanju-idle.png` 降级图。恢复点击、挥手、走动、注视、拖拽落地、打盹、关键词整理/拖拽/键盘移动、菜单暂停和回中央。
- 标题依次为「简单 → 好用 → 好玩 → 清楚」，正常模式 8 秒切换。手动点击可换词；可暂停。页面隐藏、标题离屏、换词按钮聚焦或说明书打开时暂停计时。减少动效默认停止自动轮换，保留手动操作。
- 四季改变叶色与场景底色；冬季带轻霜基调。晴、雨、雪、雾独立选择，支持全部 16 种季节/天气组合。雨有雨线、积水与涟漪；雪有飘雪、屋面和地面雪色；雾使用真实深度雾。
- 朝阳、薄暮、夜色调整环境光、方向光、灯笼和室内暖光。
- 题名最多 8 个 Unicode 字符，真正绘制到匾额；掀开屋顶显示茶案与文房。
- 设置显式保存在本机 localStorage。分享 URL 还原题名、季节、天气、灯光、屋顶状态。快照导出合成三维画面与天空背景的 PNG。
- WebGL 不可用时显示原场景静态预览，明确提示，不假装实时切换或提供不可用截图。可设置配方后分享/保存，支持重试。
- WebGL 场景离屏/后台时停止绘制；正常模式上限约 30 帧，减少动效按需绘制；分辨率封顶 1.5 倍并可按运行样本降至 1 倍。
