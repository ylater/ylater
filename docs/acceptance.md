# 升级验收清单

## 自动化检查边界

```sh
npm run check
npm run build
```

`check` 仅检查 main.js、pet.js、build.mjs 和 serve.mjs 的 JavaScript 语法，不等价于 lint、单元测试或功能测试。当前没有配置 lint、typecheck 或单元测试命令；项目没有 TypeScript。

`build` 清空并重建 dist。执行前留意产物中是否存在需保留的手工修改。文档变更无需重新构建站点。

## 用户人工 UI 验收

不使用 computer use 或浏览器自动化进行 UI 测试。以下项目需要用户在开发页及构建预览中人工验证，尚未勾选即表示未验收。

- [ ] 桌面、平板和窄屏手机布局无横向溢出；标题、关键词、猫咪和作品入口不发生影响操作的遮挡。
- [ ] 标题四组词按顺序切换，提示与可访问名称同步。
- [ ] 五个详情入口显示对应内容；关闭按钮、Esc 和外部点击有效；关闭后焦点回到原入口，页面滚动恢复。
- [ ] 关键词点击显示对应观点；拖动后不误触点击；方向键、Shift 与 Home 操作正常。
- [ ] 点击猫咪或整理菜单可切换关键词布局；整理后缩放窗口仍能正常排列。
- [ ] 猫咪挥手、注视、行走、拖拽、落地、休息、回中央行为正常，未移出舞台。
- [ ] 拖拽中取消指针操作、快速连续点击、弹窗打开/关闭没有卡住角色状态。
- [ ] 菜单可通过鼠标、触屏、键盘使用；方向键、Home、End、Esc 和 Tab 行为可用，暂停状态文字一致。
- [ ] 暂停自动走动后不再自动游走，主动交互仍可操作；恢复后行为正常。
- [ ] 操作系统启用减少动效后，无非必要大幅动画，手动交互可用；运行中切换偏好也正常。
- [ ] 切换到后台或将舞台滚出视口，再返回后动画恢复，无明显位置突跳。
- [ ] 模拟图集加载失败时静态猫图可见，点击仍能整理关键词。
- [ ] 全程键盘操作焦点可见；屏幕阅读器能识别按钮、弹窗标题及状态提示。
- [ ] 点击品牌恢复标题、关键词和提示，小猫回到中央；页脚年份正确。
- [ ] 构建预览中样式、静态猫图、图集等资源正常加载；控制台无新增错误。
